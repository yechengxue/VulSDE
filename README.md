# VulSDE: Vulnerability Detection via Program Slicing and Dependency Edge Enhancement

This repository contains the source code for the paper:  
**"Vulnerability Detection via Program Slicing and Dependency Edge Enhancement"**

## 📌 Status
> **Code will be made publicly available upon publication.**

## 📋 Overview
VulSDE is a source-code vulnerability detection method that combines:
- Fine-grained bidirectional program slicing
- Degree centrality-enhanced node representation
- Dependency-edge-enhanced Gated Graph Neural Network (DE-GGNN)

## 🛠️ Requirements
- Python 3.8+
- PyTorch 2.4.1
- CUDA 11.8 (optional, for GPU support)
- Joern 1.1.1125
